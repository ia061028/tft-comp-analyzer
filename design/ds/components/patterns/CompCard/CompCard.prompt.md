# CompCard

構成カード。一覧の主役。

**情報要素（落とさない）**: 順位番号 / 平均順位（生の値）/ 同ユニット数の平均との差分 /
盤面（ユニット・コスト色枠・スター・完成アイテム・**紋章の装備者は金リング**）/ 特性チップ /
副指標（Top4率・1位率・採用数）/ チームコードのコピー。

**灯（左の縦線と数字の色）は3段のみ**: `comp--hot`(差分>=0.8) / `comp--warm`(>=0.3) / `comp--cold`。
灰は「その規模として普通」＝**無信号**。劣っているという意味ではない。段を増やさない。

**レイアウト**: デスクトップは `順位 | 平均順位 | 盤面 | 副指標 | コピー` の1行（grid-template-areas）。
特性チップは**ユニットの右**に流す（上に積むとカードが縦に伸び、盤面列の右に大きな空白が空く）。
モバイルは縦積みで、コピーは全幅（最大の対価アクション）。

**制約**: 1440×900 で 9 枚見えている状態を保つこと。カード高は約 88px。
