# Colors

**光源は3つに限る**。それ以外は黒鉛（無彩色）。**光っているものは必ず意味を持つ。**

1. **灯**（`--color-ember-*`）— 平均順位の優位量。**同じユニット数の平均との差分**で決まる。
   平均順位はユニット数にほぼ支配される（6体=5.86 … 10体=2.05）ため絶対値では比較できない。
   灰は「その規模として普通」＝無信号。閾値は実データ較正（赤9% / 橙20% / 灰71%）。
2. **階級**（`--color-cost-*`）— TFT 公式のコスト色。プレイヤーの既存知識をそのまま使う。
3. **手の内**（`--color-hand`）— 選択中の紋章。金はここにしか出ない。

コスト5の金と手の内の金は同系だが、出る場所（ユニット枠 / 紋章タイル）が完全に分離しているため許容。
**新しい色を足さない。** 足すなら「それは何の意味を運ぶのか」を先に答えること。
