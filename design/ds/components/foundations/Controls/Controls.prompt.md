# Controls

操作要素の高さは `--ctl-h`（デスクトップ 32px）。**モバイルでは `--ctl-h` 自体が 44px に切り替わる**
（`@media (width < 48rem)`）。個別に指定すると必ず取りこぼすため、トークンで一括で切り替える。

- `.seg` / `.seg__btn`（`--on`）— 単一選択。ツールバーで使う
- `.icon-btn`（`--on`）— 歯車。開いているときは `--on`
- `.input` — 数値入力（採用数下限）。歯車の中だけに存在する
- `.tile`（`--on` / `--over`）— 紋章。`--over` はデータ上活用できない枚数の警告
- `.empty` — 空状態。文章は1行まで（説明しすぎない）
